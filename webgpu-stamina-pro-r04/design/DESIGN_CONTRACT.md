# スタミナ回復E r0.4 CONFLUENCE — 設計契約

## 1. 対象
- 対象は**権威ある正の gain-stamina 一件**のみ。
- 自然回復の毎tick、速度上昇、継続バフ、周辺への配布は描かない。
- 受益者本人の身体Eであり、頭上マーカーではない。
- actor-time に追従し、既定 1500ms、最低 900ms、基準 radius 82 を維持する。
- 満了、死亡、退出、不可視、時計逆行、明示 cancel で終了する。
- 同一原因の重複は開始・SFXとも再発しない。

## 2. r0.3の観察を踏まえたr0.4の判断
r0.3のH64観察では、三つの淡青色の塊が初期に身体周囲へ離れて見え、中盤で胴体へ寄り、後半は胸腹の発光が静止に近く見えた。全寿命連続観察やSFX実聴は未実施なので確定欠陥とは断定しない。ただし、**H64原寸で「外部の蓄えが減る → 身体へ移る → 身体の容量が満たされ定着する」因果を、主形だけで読む**という目標に対しては、より一体的な供給構造へ改稿する価値があると判断した。

## 3. r0.4の主形
主形は四層。
1. **外部蓄え層**: 左右と下部の厚い蓄えを、上部クランプと前面ハーネスで連結した**一体の供給構造**として見せる。分離した三つの浮遊物に見せない。
2. **送達層**: 供給構造から身体中心へ向かう三本の短く太い送達胴を出す。細線・粒子・リボンにはしない。
3. **身体容量層**: 胸上部、腹部、腰の三室を丸い体積として満たし、運動に使える容量が身体内部へ定着したと読めるようにする。
4. **内部連結芯**: 三室を縦に結ぶ芯を薄く残し、充填された容量が一つの身体内部システムとして見えるようにする。

## 4. 因果と共有状態量
- 外部蓄えの残量 `outside = 1 - Q(t)` と身体側の充填 `charge = Q(t)` を同じ sampler から生成する。
- `flux = dQ/dt` は送達の強さ、局所発光、身体受光、SFXの起音から余韻までの共通入力とする。
- したがって、外部蓄えが減るほど身体側が満ち、送達ピークと発光ピークが同時相になる。

## 5. 時相
- **establish**: 一体供給構造が現れる。
- **deliver**: 供給構造が減り、送達胴が身体へ押し込まれる。
- **fill**: 胸腹腰の三室が順に満ちる。
- **hold**: 形を一度だけ引き締めて定着し、主形は安定する。
- **release**: 主形の明るさだけが消える。SPが失われる演出にはしない。

## 6. B Foundation 基底の適用
以下を適用する。
- 因果優先: 見た目より、外部蓄え・送達・身体容量の関係を主形に埋め込む。
- PH/OBS分離: 供給構造・送達・容量は world 側、局所拡散は observation 側に分離する。
- H64可読性: 拡大時だけ見える細部で成立させず、厚みと体積で読む。
- 非テクスチャ: すべて解析的な体積で構成する。
- 実行/品質の分離: 静的検査・実GPU・実聴・採用を混同しない。

## 7. 選択した拡張と理由
必要最小限のみ選択する。
- **VFX**: world層とOBS層を分け、供給構造／送達／身体容量／局所拡散を階層化するため。
- **LDM**: 発光の強弱を単なる一律増光ではなく、送達流束・受納量・局所拡散へ接続するため。
- **Observation Integration**: 明暗背景、人物の前後遮蔽、人物表示/非表示を同一ロジックで扱うため。
- **VideoGenerationPolicy / sampling contract**: H64原寸、1500/900ms、通常/2倍actor、近接二件、正常終了と取消を検証ループへ固定するため。

採用しないもの。
- KeywordExpansion / 装飾語中心の見た目増し: 因果より表層装飾へ寄るため不採用。
- 背景依存の増減光ポリシー: 背景ごとの補正で成立させないため不採用。
- テクスチャや粒子群: H64で主形を曖昧にしやすいため不採用。

## 8. SFX契約
- 起音: gainの開始時に一回だけ。短い吸い込み気味のノイズ＋クリック。
- 送達: `flux` に連動した帯域ノイズで、運動量が身体へ入る印象を作る。
- 充填: 身体容量が満ちるほど基音を安定化させる。
- 余韻: hold後半から短い残響成分を残し、releaseで消す。
- 同一原因は一声のみ。毎frameの再startは禁止。

## 9. 拒否条件 / failure patterns
- 自然回復や継続速度上昇を想起させる反復パルス。
- 供給源が無関係な三つの浮遊物に見えること。
- 胸腹の発光平板だけが残り、容量としての厚みが読めないこと。
- 背景色依存の色替え、増光、減光に頼ること。
- CPU 2D 代理描画や単フレーム確認を品質合格扱いすること。

## 10. 実行境界
- WebGPU / WGSL / pipeline の**静的検査は実GPU保証ではない**。
- 制作環境での実GPU描画・実聴は `not_run` のまま記録する。
- 品質採用・本編接続は**未承認**。
