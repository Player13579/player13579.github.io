# 選択した B 拡張と理由 / r0.3

基底は現行の **B Foundation** を適用します。拡張は「必要なものだけ」を選びます。理由のない一括展開はしません。機械可読の正本は `docs/B-Expression-2.json` です。

## 採用した拡張

| 拡張 | 選択理由 | この制作での使い方 |
|---|---|---|
| `VFX` | 依頼対象が明示的な世界内現象だから | 身体脇の受容外套、変換界面、身体内 reservoir、定着帯、低明度定着核を別役割として設計 |
| `LuminanceDynamicsModule` | 局所発光 / 暗部対比 / 低明度終端が必須だから | 相ごとに輝度・coverage を別制御し、終盤を白飛びや灰板にしない |
| `BeautifulPoseCapsule` | 身体との接触・前後・H64 判読性を扱うため | プレビューでは standing の診断ボディを固定使用。実ゲームのポーズ制御そのものは上書きしない |
| `GradientAnchorPolicy` | 変換界面に意味のある色遷移が必要だから | 外套 → 界面 → reservoir の遷移位置にのみ色変化を与え、背景依存グラデーションにはしない |
| `VideoGenerationPolicy` | actor 時相の連続再生と全寿命確認が必要だから | 1500ms / 900ms、1× / 2×、単発 / 近接3回、余韻から消去までを単一 timeline として扱う |

## 採用しなかった拡張

| 拡張 | 不採用理由 |
|---|---|
| `PostEffects` | 独立 bloom / flare / grain を追加せず、主形そのものの可読性で解決する方針のため |
| `KeywordExpansion` | 今回は明示キーワード選択で制作する依頼ではなく、設計判断を実装側で行うため |
| `CharacterPolicy` | 本 ZIP の preview body は人格属性を持たない診断ボディであり、新規人物設定を要しないため |

## 補足

- 旧 Sol / Astra や他Eの既存造形を、拡張選択の根拠にしていません。
- ReflectionClosure は意味のある鏡面表現を採らないため、基底側で非適用のままです。
- `not_run` の実GPU / 実聴項目は、拡張を選んだことだけで合格になりません。
