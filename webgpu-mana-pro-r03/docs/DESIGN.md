# 身体受容脈 / r0.3

## 設計課題

マナ獲得Eは、**権威確定した正のマナ増加**が、受益者の身体へ獲得・吸収・定着する現象です。頭上マーカーではなく、身体・身体周囲で読める必要があります。

r0.2 の実 GPU 観察では、H64 で「胴に差し込む楕円」「弱い発光」「平板な終端」が問題になりました。そこで r0.3 では、**飛来物に見える主形**をやめ、**身体所有の現象**として主形と因果を再設計しました。

## 主形

r0.3 は 5 つの要素で構成します。

1. **Intake Shroud（受容外套）**
   - 身体脇の受容縁に最初から接続した外側主形
   - detached object ではなく、身体側の開口 / 受け皿として読む
2. **Conversion Seam（変換界面）**
   - 外套の内側を走る、局所的な明るい変換前線
   - 何が「流入しているか」を時間的に示す
3. **Reservoir（身体内蓄積容積）**
   - 吸収相で身体内に増える中心状態
   - 外側が減るほど内部状態が強まる
4. **Settlement Bands（定着帯）**
   - 定着相で短い帯が胸部内に並び、蓄積完了を示す
   - バッジや UI ではなく身体内の層状態として扱う
5. **Terminal Seed（低明度定着核）**
   - 終盤の低明度余韻
   - 灰色の平板楕円にせず、コンパクトな低明度核へ収束させる

## 時間因果

| 相 | 正規化 | 目的 |
|---|---:|---|
| 発生 | 0.00–0.15 | 身体脇の受容縁が起動し、外套が立ち上がる |
| 変換 | 0.15–0.43 | 変換界面が前進し、外套が身体内状態へ変わり始める |
| 吸収 | 0.43–0.72 | 外側主形が縮退し、身体内 reservoir が増える |
| 定着 | 0.72–0.88 | settlement bands が短時間残り、蓄積が身体へ座る |
| 余韻 | 0.88–1.00 | 定着核だけが低明度で残り、期限で消える |

## 可読性方針

- H64 実寸で読むため、**少数の大きい主形**を優先
- 白塊、上昇粒子、拡大円環、意味の薄いノイズは不採用
- 暗部と局所高輝度の対比を持たせるが、全面 bloom へ逃げない
- 背景色には最適化せず、暗背景 / 明背景のどちらでも同じ effect を使う
- 前後関係は背面 / 前面ターゲットで保持し、前景遮蔽はホスト / プレビュー側で確認する

## SFX 設計

SFX は一原因一声です。音は 3 相で設計しています。

- ingress ping：受容開始
- conversion sweep：内部変換
- seated body tone：定着と収束

rate 2× では壁時計長もピッチも同じ因果で変わります。ピッチ保持型タイムストレッチは使っていません。

## B Foundation / 拡張の使い方

基底は現行の B Foundation を前提にし、拡張は `docs/EXTENSIONS.md` で選択理由を明示しています。全拡張の一括適用はしていません。機械可読の設計は `docs/B-Expression-2.json` です。
