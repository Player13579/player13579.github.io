# 独立Mana E r0.3 — 連続面・受領充填

Defenders vs Attackers向けの**ギャラリー候補**です。WebGPU/WGSLで手続き的に描画し、固有の単発SFXを再生します。ゲーム・公開サイトを変更する処理、マナを付与する処理、Canvas 2D、画像素材の描画依存はありません。

**r0.3の実GPU描画・聴感・無説明での品質観察は `not_run` です。** Node/mock・CPU式・構造検査のpassは、H64で因果が読めたという証拠ではありません。r0.2のユーザー実観察は別版の報告としてのみ記録し、原因パラメータを特定していません。

## 起動

Node.js 20以上の環境で、このREADMEのフォルダーから `npm start` を実行し、表示された `http://127.0.0.1:8783/` をChromeで開きます。Windowsは `START-Windows.bat`、macOS/Linuxは `START-macOS-Linux.command` も使用できます。依存パッケージのインストールは不要です。サーバーはlocalhostだけで待ち受けます。停止は端末のCtrl+Cです。

`file://` からの直接起動ではなく、ローカルHTTPを使用してください。WebGPUが利用できない場合は説明を表示して停止し、別方式で偽装再生しません。

## 初回の品質観察

プレビューは **暗・明を左右に並べたH64原寸、無音、位相説明なし** で開始します。「1件再生」「全寿命リピート」を使い、まず説明や層分解を開かずに観察してください。源、そこから切れずに続く輸送、受領先、受領側に増える量を視覚だけで区別できない時間帯がどちらかの背景にあれば棄却です。

H64は基準高128 world unitsを64 CSS pxとする設計仮定です。実行時の1×表示ではキャンバス480×208、scale=0.5。ブラウザー100%で観察し、Windows表示スケール・DPRも記録してください。2×/4×は補助検査でありH64の合格に数えません。人物の仮原画はありません。

音は「音声を有効化」のユーザー操作後にだけ利用できます。ミュート解除で過去イベントを追い鳴らししません。リピートは新しいevent idを発行する試験モードであり、常時ループ音ではありません。リピート解除で新規発火を止めます。

## 検査コマンド

`npm test` はイベント、時計、音声mock、表示量・接合・有限値のテストです。`npm run check` はJavaScript構文、描画依存、ローカルB構造・参照・実装アンカーを検査します。`npm run check:field` は161位相のCPU解析場を検査します。いずれも実GPUや聴感を代替しません。

サーバー起動後に `http://127.0.0.1:8783/tests/verify.html` でshaderコンパイル、161位相・暗明のGPU画素、主形の色差などを実行できます。検査ページはAudioContextを作りません。結果JSONの技術欄と手動品質欄は別です。検査ページの静止画列だけで「全寿命を無説明で読めた」と判定しないでください。

`npm run verify:hashes` は配布時の整合性確認です。`manifest.json` はmanifest自身とSHA256SUMSを除いた全ファイルを列挙し、`SHA256SUMS` はmanifestを含む全ファイル（SHA256SUMS自身だけ除外）を照合します。再生成・検査がevidenceを書き換えた場合は別の作業コピーで実行し、配布物の整合確認と混同しないでください。内容更新後のハッシュ再作成は `npm run build:manifest` です。

## 状態と限界

作成環境のChromiumはlocalhostへの移動を `ERR_BLOCKED_BY_ADMINISTRATOR` で拒否し、GPU初期化まで到達しませんでした。GPUコンパイル、GPU画素、実デバイスの同期・聴感、H64の読解、ゲーム接続は `not_run`。詳細は `evidence/validation-summary.json` を参照してください。

このパッケージはゲームに挿入済みのプラグインではありません。ホストが正の確定値、受け手の現在位置と可視性、実効移動ACC2の切替時刻を渡す必要があります。腹部アンカーと実キャラの重なり、実景への受光、透過合成・前後関係は未検証です。プレビューの背景を実ゲーム背景として扱わないでください。`docs/INTEGRATION.md` に信頼境界と制限を記載しています。
