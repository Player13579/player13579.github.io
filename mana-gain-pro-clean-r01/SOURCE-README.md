# Defenders vs Attackers — 通常の正の離散マナ獲得 E

**内向きの蓄積 / Inward Deposit — 独立ギャラリー候補**

このパッケージは、WebGPU / WGSLの実行ソース、手続き合成した単発SFX、H64プレビュー、設計と検査をまとめたものです。画像生成モデルのprompt、画像生成用Python、既存Mana Eの改造品ではありません。ゲームのマナ値や他の状態を書き換える機能はありません。

## 現在の検証状態

`validation/report.json` が実検証の正本です。JavaScript構文、イベント契約、時間積分、SFXの数値・発音ゲート、設計構造のNodeテストを実行しました。

**WGSLのGPUコンパイル、実GPU提出、実画素、画面上の動き、聴感、実ゲーム接続は `not_run` です。** 制作環境のブラウザがローカル検査ページを `ERR_BLOCKED_BY_ADMINISTRATOR` で拒否し、shader実行へ到達できませんでした。GPU描画の成功やH64品質合格を主張しません。実行ソースを作成したことと、その環境で実行・観察できたことは別です。

継承B仕様の版は記録していますが、正本のGit `source_commit` / `base_blob` / `extension_blob` は会話に提示されていません。`design/source-basis.json` の該当値はnullであり、Git正本凍結条件は未完了です。候補ファイルのSHA-256をそれらの代わりに偽装していません。

## 起動

Node.js 20以上の環境でZIPを展開し、このREADMEのあるディレクトリで `npm start` を実行してください。npm依存パッケージのインストールは不要です。表示されたローカルURLをWebGPU対応ブラウザで開きます。標準ポートは8080、別ポートは環境変数 `PORT` で指定できます。

`index.html` を直接file URLで開く方法ではなく、同梱のHTTPサーバーを使用してください。WebGPU非対応・無効・device lostでは停止し、Canvas 2DやWebGLへの代替描画は行いません。

トップページは暗背景・明背景それぞれのH64実寸と、その**同じ画素**の4倍表示を備えます。「全寿命を繰り返す」は毎回異なるプレビューevent idを発行する試験機能です。E本体やAudioBufferをループさせる機能ではありません。

音は初期ミュートです。「音を有効化」をクリックするとAudioContextを起動し、その後の新しい可視イベントから一回音が可能になります。過去の抑制済みイベントを遡って鳴らしません。位相スライダーは無音の表示検査です。URLへ `?verify=1` を付けると、そのページでは音を起動できません。

## H64の解釈

ゲーム側のworld-unit→pixel変換は未提示です。これを確定したゲーム事実にせず、プレビューに二つの明示的検査条件を用意しました。

- 既定の厳しい条件: E枠の全高140wuを64pxへ縮小する。倍率は `64/140 px/wu`。
- キャラ高基準の仮定: 128wuのキャラ高を64pxとし、倍率を `0.5 px/wu` とする。E枠全高は70pxになる。

どちらでもCanvasは100×86 raster / 100×86 CSS pxです。高DPR環境でもrasterを自動的に増やしません。実寸の検査はまずブラウザ倍率100%、DPR1を推奨条件として実施し、他条件を別に記録してください。ゲーム導入時は実際の `project` が返す倍率を使います。

## 形態と時間

単一の足元源は、暖色中心と有色面を持つ小さな閉形です。そこから**厚みのある青緑の輸送体**が体幹へ進みます。受領中心に到着した後で、閉じた受領域の面積と内部の充填量が増えます。最後は外へ散らず、同じ体幹中心へ縮んで消えます。

源・輸送・受領・局所光・狭いsource-bound拡散を別の機能として実装しています。源と輸送は同じPH、受領蓄積と局所放射はそれぞれ別PHです。OBSは外縁PSF近似とsRGB出力変換です。単なる同形状の色違い重ね、単調な粒子上昇、全面均一のglow、ランダムノイズは使っていません。

源は足元相対 `(0,-8)wu`、受領中心は既定で `(0,-65)wu`。本体・局所光・OBSを含めて `x∈[-66,66], y∈[-127,13]wu` のquad内に収めます。キャラや代用人形は描画しません。**そのため、実キャラへ入ったと読めるか、スプライトとどう重なるかは、実ゲームまたは許可された実キャラ素材を使う別の検査が必要です。** 体幹への到着・蓄積の品質合格はまだ判定していません。

`CONTRACT.duration` は **1.36 owner-effective秒**です。定義箇所は `src/contract.js` の一つだけで、shaderにはuniformとして渡します。WAV長も同じ値から生成します。全寿命を実効ACC2で進めた場合の実時間は0.68秒です。待機・予約・OFF・非実効activeでは1倍です。途中切替時は、前の区間を積分してから新しいrateを適用します。

表示量の `source + inTransit + received = 1` はE内の規格化した表示契約です。ゲームのマナ残高や物理的なエネルギー・質量を生成する処理ではありません。p=1で描画と発音は終了しても、ゲームの獲得済みマナには触れません。

## SFX

`audio/mana-gain.wav` は48kHz、stereo、PCM16、65,280 sample framesのオリジナル手続き合成です。短い発生音、輸送に沿う吸入的な音高移動、到着後の受領和音、短い収束尾部で構成しました。外部録音・既存Mana音・引用旋律は利用していません。

実行時は同じ `src/synth.js` からFloat32のAudioBufferを作成します。配布WAVはそのPCM16書出しなので、量子化差以外は同じ設計です。ACC2は同じAudioBufferSourceの `playbackRate` を1/2に変更し、音を再発音しません。ピッチ保持のtime-stretchではないため、2倍速時は音高も上がる設計です。

SFXの再生機会は、同じevent id/tokenについてGPU提出・validation・正のocclusion sampleが確認され、再度可視性とscopeを確認したときの一度だけです。ミュート・非表示・verify・AudioContext未稼働でその機会を逃したイベントは、後から再生しません。セッション・ルーム変更時はvoiceを停止し、古い非同期結果をgenerationで無効化します。

`onSubmittedWorkDone` とocclusion queryは、GPU作業と描画サンプルの検査です。OSの画面提示時刻やDACからの発音時刻を保証するものではありません。ブラウザ・GPU・音声出力の遅延を実機で測る必要があります。提出後のフレームを過去に遡って消すこともできません。前後の可視性チェックと遅延結果の取消し、直後の空描画を実装しています。

## ゲーム接続の境界

`src/index.js` が公開入口です。`src/index.d.ts` に正規化イベント・受け手・owner・表示条件の型を記載しています。`docs/INTEGRATION.md` に接続順序と未接続部分があります。ネイティブゲームAPIの名前や構造を捏造せず、ホストが正規化する明示的境界を用意しています。

受理対象は実際に確定済みの `gain-mana / effectKind=mana`、正の実差分、離散イベントで、原因がmap-objectまたはMysteryのmana-surgeであるものです。0/負値/上限で無変化、自然回復、既知の錬気3variant、重複ID、不可視や別scopeは対象外です。

描画は受け手の**現在**のworld位置を読みます。`ownerPlayerId` はE時間の所有者で、観測者や送信者へ勝手に置き換えません。map-objectなどで所有者と受け手が同じなら、ホストが両方に同じIDを渡してください。所有者が異なるイベントでは実際の発動者IDを渡します。

同時実行の実装上限は64件、同一セッションの重複台帳上限は100,000件です。上限時はIDを忘れて再生するのではなく、明示的なcapacityエラーでfail-closedします。無制限負荷で全イベントを表示できるとは主張しません。ゲーム導入時には想定上限を確認してください。

## テスト

`npm test` はNodeの単体・契約・構造テスト、`npm run check` はJavaScript構文と禁止依存の検査、`npm run verify:hashes` は配布物の整合性検査です。

`npm start` 後に `/tests/browser.html` を開くと、WGSL compilation infoを取得し、「全寿命の画素検査を実行」で暗/明背景の102フレームをGPUからreadbackする検査を実行できます。成功時も、受領の意味・聴感・ゲーム統合まで自動合格にはしません。手動の受入項目は `docs/ACCEPTANCE.md` を参照してください。

任意の自動化用に `tools/browser-check.py` も同梱しました。PythonとPlaywrightおよび対応ブラウザが別途必要です。起動中のプレビューURLを指定して実行し、検査結果JSONを保存します。環境で実行できない場合はnot_runを残します。

`src/` 実行ソース、`shaders/` WGSL、`audio/` SFX、`tests/` 実行検査、`design/` PH/OBS・基底拡張対応・出典制約、`docs/` 受入と統合手順、`validation/` 実行済みの記録、`manifest.json` ファイル台帳、`SHA256SUMS` ハッシュ一覧。

ハッシュは配布ファイルの整合性の確認用であり、設計の妥当性・GPU合格・聴感・正本BのGit IDを証明するものではありません。
