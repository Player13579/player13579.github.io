# 状態契約 / r0.2

## 表示の原因と権威

入力は「ゲームの権威が確定した、有限で厳密に正のマナ増加」です。`committed === true`、`manaDelta > 0`、現在の `sessionId` が必要です。本Eは資源値を増減・予約・再確定しません。後半の吸収・定着相は既に起きた増加を可視化するもので、資源確定を遅らせる処理ではありません。

`beneficiaryPlayerId` が配置・身体・可視性・消去の所有者です。`actorPlayerId` は原因のactor時計の所有者です。両者を同一視せず、受益者の時計へ自動代入しません。

## 二つの台帳

VFXの識別は `[sessionId,eventId,beneficiaryPlayerId]`、SFXの識別は `[sessionId,eventId]` です。JSON tupleで符号化し、区切り文字を含むIDで衝突させません。同じ原因を複数受益者へ通知しても音は一回だけです。異なる三原因は三声です。描画フレームや相の切替から新しい声は作りません。

検証済みの通知は受益者ごとに消費されます。受益者が透明、退室、死亡、ベント、対象不存在、活動上限で抑止された場合にも同じ通知を復帰後に再生しません。無効入力は拒否し、予測イベントを予約キューにしません。消費済み台帳は同一セッション内で期限切れにせず、容量超過時は古いIDを捨てずにfail closedします。

同じ原因についてactor所有者、開始actor時刻、寿命を後の通知で変更できません。一人だけが消えた場合、同じ原因の別の可視受益者が残る間は共通音を維持します。最後の受益者が消えれば音も取消します。

## 時相

唯一のE年齢は `getActorClock(actorPlayerId).timeMs - startedAtActorMs`。年齢へ `rate` を再乗算しません。通常1500 actor-ms、最小900 actor-ms。2×なら1500 actor-msが約750 wall-msへ圧縮され、相とSFXのサンプル進行も同じ比率になります。時相停止rate=0ではEの形を保持し、音はDCを出さず無音で停止します。

r0.2の視覚相は次の新規設計です。関数は `src/sampler.js` が正本です。

| 相 | 正規化年齢 | 1500ms時 | 可視因果 |
|---|---:|---:|---|
| 発生 | 0–0.14 | 0–210 | 身体脇に接する一つのまとまった容積が立ち上がる |
| 変換 | 0.14–0.40 | 210–600 | 曲がった内部界面が進み、容積の状態と位置が変わる |
| 吸収 | 0.40–0.70 | 600–1050 | 外の占有域が減り、身体内の充填が増える |
| 定着 | 0.70–0.84 | 1050–1260 | 外側は終端へ、胸郭内の容積が状態保持を示す |
| 余韻 | 0.84–1 | 1260–1500 | 輝度とcoverageを別々に低下させる |
| 消去 | 1以上 | 1500以上 | 描画プリミティブと活動状態がゼロ |

相をまたいで層の包絡が重なります。表は新しいイベントを発生させるスケジュールではありません。900msでは同じ相を0.6倍のactor時間へ写像します。既存ゲームのサーバー時刻とactor時刻の換算はホスト責務です。

## 消去

期限切れ、死亡、退室、ベント、透明化、対象欠落、時計欠落・不正・巻き戻り、明示取消し、セッション切替、disposeで除去します。任意の相から消去でき、同じ原因の自動復活はありません。APIファサードの取消しは描画済みバッファの有効フラグも落とします。ホストは通常どおりフレームを再描画し、キャンバスの古い画素を残さない必要があります。SFX取消しの反クリックreleaseは最大4ms（デバイス出力遅延を除く）です。

## 非対象と承認

`route='desire-refinement'` はDESIRE専用の錬気マナ演出なので拒否します。他の獲得経路は同じ表現を使い、経路や背景模様で造形を変更しません。任意のホストが `committed` を偽らないことの暗号学的証明は行いません。実DVAへのイベント配線、既存Eとの共存、実ゲームのスキン・遮蔽・音量承認は `not_run` です。本編接続は承認していません。
