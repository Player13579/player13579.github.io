# 参照範囲

創作の外部参照は無し。旧Sol/Astra、既存E、r0.1/r0.2 ZIPの内部、採用済みヒールの図形/色/層/時間/音/コードを閲覧していない。

ゲーム契約とB Foundationはこのチャットのユーザー提供本文。r0.2の失敗事実はユーザーの実Chrome全寿命H64暗明報告として記録。元画像/録音をこちらで観察したという主張ではない。

技術API・言語に限って参照:
- W3C, WebGPU Shading Language, 2026-09-21 Candidate Recommendation Draft, §16.2 reserved words. `meta`は予約語。`tools/wgsl-lexicon.mjs`に言語トークン表を収録。https://www.w3.org/TR/2026/CRD-WGSL-20260921/#reserved-words
- MDN, GPUShaderModule.getCompilationInfo(). コンパイル診断の取得。https://developer.mozilla.org/en-US/docs/Web/API/GPUShaderModule/getCompilationInfo
- MDN, GPUDevice.createRenderPipelineAsync(). pipelineの非同期生成結果を待つ。https://developer.mozilla.org/en-US/docs/Web/API/GPUDevice/createRenderPipelineAsync
- W3C, Web Audio API 1.1, AudioWorklet. 処理スレッドと音声時間に関する標準。https://www.w3.org/TR/webaudio/#AudioWorklet

参照はAPI意味の確認だけで、VFXの見た目やSFXの創作入力にしていない。参照文書を実行環境でテスト済みという意味には用いない。
