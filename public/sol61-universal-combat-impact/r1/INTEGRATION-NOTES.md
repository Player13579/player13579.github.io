# 汎用戦闘衝撃 R1 候補メモ

対象は `pushHitEffect` の一般通知。通知は被弾だけでなく、防御吸収・バリア・過剰回復・特殊解決にも使われる。銃器、ヘッドショット、攻撃者、精密な接触点、ダメージ範囲や撃破を意味づけない。`lethal` は既存ホストの寿命選択だけに使い、見た目は同じにする。

`plan-function.js` は `webgpu-hit-effects.js` の `plan(...)` 置換候補。既存の `hsl`, `seedFor`, `TAU`, `finite`, `clamp` helper、`shapes.enqueue` の additive `glow` / `ellipse` 命令を使う。既存 `record(...)` とapp側のイベント重複排除・時計・ローカル対象音声は維持する。旧22粒子・交差スパーク・リングと重ねない。

**状態：** 関数単体のNode検査は成功。ゲーム統合、GPU実再生、画面品質、既存音の聴感、ギャラリー親子プロトコルは未検証。この枝だけではギャラリーに掲載できない。実際のギャラリー・Pages反映はDotが現行headへ統合し、全受入後に行う。

表示の広いglowは加算合成による局所スクリーン発光。現行ヒット挿入点に受光面・深度・法線がないため、世界面を物理照明したとは主張しない。近傍の読みやすさが不足する場合、Dot側で受光契約を追加するか、受入基準を満たす表現へ再設計する。
