# GBO・1弾倉射撃開始 R1 候補「一枚の刻み面」
ギャラリーのみ、dot。正本の `gbo-overdrive / magazine-commit:weapon:<id>` はGBOモードで射撃状態確定の直後、初回射撃処理の直前に発行される。装填完了、命中、残弾数、武器破壊とは異なる。アクター近くの一枚の薄い圧刻面へ横溝が刻まれ、外側へ短い面の反応を伝えて、溝ごと消える。溝は刻面固有のテクスチャで弾数を表さず、射撃方向・銃口・波及先は描かない。低モーションでは面の位置を動かさない。銃声・薬莢音・武器の割れ・剣などは描かない。破壊の既存抽象剣演出はそのまま。
参加者に範囲や向きを示す戦闘情報ではなく、プレビューは発行本人の確定表示に限定。実コードは触らない。一般の武器破壊や射撃のライブラリに別版として追加しない。
