# ミネラルウォーター通常使用 R3「口元に留める飲み口」
作者 dot、ギャラリー専用、本編接続・採否未確認。v920の通常自己使用由来の本人リプレイ（gain-stamina / stamina / mineral-water:use / 半径82 / wire 1500ms）で、既存正規照合をそのまま使用。満タンでも通知が発生する契約なので、水量、回復量、得失、回復・燃焼解除の成否を示さない。投擲、受け手、水域、飛沫、別の道具を足さない。生wireの配信個人限定を主張しない。

R1は手と容器の持ち上げおよびその水面、R2は角短瓶を持った手が口元から下へ移動することで読ませる。R3は同じ一瓶の飲み口を唇の位置に固定し、**手首と底だけが口元を支点に上がり、短く止まり、元へ戻る**。約46°を一度だけ回転させ、持ち上がり/戻りは輪郭で判別できる。容器空間の外へ反射を延ばさない。軽減時の固定傾きは移動帯や明滅なし。口縁だけに入る反射の弱い時間包絡で動作を支える。SFXは旧R2と同じ一音を保持し、内容の違いを示さない。終端1060ms。

現行制作スキルの観測・設計・完成検査、B基底4660b1b/拡張e0fe7a0のLDM「画面占有と局所コントラスト・必要な時間包絡」を適用。体と容器・口の遮蔽を保ち、床／顔全体を発光させず、広域で明暗に依存した調整は行わない。
