# 通常対戦の決着 R1「閉じる競技面」
勝者を知らせるバナーではなく、通常の対戦が決着して操作に区切りがついた瞬間だけの中立の演出。左右の低い透過面が床の両端から内向きに寄り、中央を大きく覆わず、床に薄い継ぎ目を残してから消える。新しい得点・MVP・勝敗・理由・名前・回数を描かない。勝者の種類ごとに見た目や音を変えない。画面全体の暗転を入れず、動き軽減では面を最終位置に固定。
