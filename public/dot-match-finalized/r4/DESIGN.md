# 通常対戦の決着 R4「余白に幕を下ろす」
R3の足元にある三面の手前→奥の折りと分ける。R4は結果枠の左余白にある縦の半透過面だけ。面は世界物体でなく画面上の固定面で、移動や回転せず、透明になる境界が上から下へ一度だけ走る。対象右側の文字・操作を明度・位置・入力のいずれでも覆わない。軽減では境界が移動せず面全体の濃度を下げる。左縦面内の遮蔽と明度勾配だけで、暗転、発光の画面外拡散、周囲への照明、再点灯なし。
