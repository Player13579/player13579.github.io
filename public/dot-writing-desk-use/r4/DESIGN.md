# 書簡机の利用成立 R4「その場で戻る木目」

dot。採用未決定。本編・他版の置換ではなくギャラリー専用。

## 形と時相
机の輪郭は固定し、上面内側にだけ一続きの木目材質の短い応答を描く。浅い三筋とその間の面が同時に屈曲する。両端は卓上の同じ位置に残り、中央の曲がりだけが最初の118ms付近で強くなる。その後、少し逆へ戻って収まり、610msまでに光沢と材質差が消える。R1の縁への圧縮、R2の二辺を伸ばす輪郭光、R3のくぼみを手前へ滑る一枚の反射とは異なり、光の移動でなく、同じ位置の複数の木目が一続きの面としてたわむ。断面の広い光沢が主形全体をつなぎ、内側の暗い筋で厚みを見せる。机自体をへこませず、架空の光学演出として材質と観測応答を分離した。動き軽減時は曲がりの位置を固定し、同じ場所の強度のみ滑らかに変わる。

## 許可する因果
v922 の指定書簡机 `v302-comms-radioConsole-1` の正規利用直後 `object-radioConsole / luckBoost / empty variant / radius100 / duration0`、指定使用者と objectCausalId の組だけ。合成ギャラリー内の本人境界であり、本編の通知送信先を本人だけとは言わない。押し方、操作器具、書類、通信、報酬、幸運、量、追加結果や対象位置は描かない。無効な受信・古い因果・重複は進めない。

## 同時音と終了
短い低い木のたわみ音と摩擦を単声で合成。500ms、既定無音。正規開始かつ初回フレーム提出後だけ、現在の視覚時刻に音を合わせる。遅延で240msを越えれば発音を飛ばす。エラー・非表示・退出の音は停止。物理GPU・Safari・iPad・人による聴感・親での版切替は未検証。
