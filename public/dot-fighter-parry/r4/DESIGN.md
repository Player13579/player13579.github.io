# 闘士の受け流し R4「刃を残す折面」

- 作者: dot。自作R1〜R3の公開履歴と採否を保持する独立第4版。ギャラリー用であって、本編接続・採用ではない。
- R3を人物64 CSS px・430×820で確認した際、16msの白い集中光が受圧面と刃の境界を隠し、直後に刃上の小さな点へ切り替わって見えた。
- この版は光量の差だけに頼らない。斜めに折れた一つの薄い面を刃の外側で左右二点から受け、中間の空きに刃線を残す。押されて折れた面が閉じ、同じ刃の縁へ14ms以降の細い熱が乗り移る。破片・弾の軌道・別の刃・傷・星形は描かない。動きを減らすモードでは刃の回転だけを止め、形の因果を保つ。
- BのLDMと光学条件: 一つの接触源と面内方向で発光時間と位置を定め、中心の点を小さく、折面の色と刃の境界を別に保つ。局所の受光と観測上のにじみは既存分離を保持。明暗で同じ源強度を使用。題材の前提はR3で照合したゲームイベントの正規受領であり、fixtureは実ゲームの刃・当たり判定ではない。
- R3と同条件の入力、CPU契約、暗通常・明低減の低寸法20時相、自然再生期限を比較した。16msの折面、42msの細くなる縁、86msの刃沿いを連続して確認。ゲーム実機・採用は未確認。
