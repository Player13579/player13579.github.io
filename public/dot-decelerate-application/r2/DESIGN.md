# ディーセラレート R2「通過の遅れる地面」
R1は左右二枚の光が静止キャラへ寄り、静止画の印象が先に立った。R2は足元の一続きの斜めの位相面に継続して稜線を通す。外側から入った同間隔の稜線が中央だけ遅く通過し、間隔が目で分かる程度に縮む。普通に流れ続ける外縁と、止まらず遅く通過する中心を同じ画面に置く。実際の発動者の方向・継続時間・解除は示さない。足元の人物を稜線で塗りつぶさず、中央の線は手前の足より低くしてエフェクトだけを読ませる。動き軽減は場所を固定して点灯間隔と密度で読ませる。音は短い周期の間隔を広げ、発動と同期させる。
対象はv920 Main/Workerの正常付与のみ。自然回復で無効化されたとき、加速・時の番人・グラビティストームや解除では出さない。ギャラリー独立、未採用。
