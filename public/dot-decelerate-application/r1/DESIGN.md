# ディーセラレート R1「遅れて通る位相」
対象に時空減速が正常に付いた瞬間のギャラリー演出。Main/Worker の gravity-decelerate、空variant、半径150、8000ms、対象座標。自然回復による無効（別variant・900ms）、加速、時の番人、グラビティストームでは出さない。発動者の位置や属性、被弾・停止・強度・効果終了を示さない。表示1140msは付与瞬間の読み取り時間で、効果終了ではない。
形：足元左右に薄い位相面を一組。外縁から普通の速さで渡ってきた連続した光の稜線が対象の近傍に入ると、前進し続けるが重くなり、後続が近づく。遅くなる局所だけ色の密度と屈折が増え、上半身・足下の接地点は遮らない。明るい面にも形が残る透過縁を用意し、動き軽減時は稜線を固定して順次点灯する。音は二つの周期が緩くなる短い音、時計・警告・被弾や完全停止の音は使わない。
