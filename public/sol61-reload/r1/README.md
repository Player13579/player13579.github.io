# Reload E R1 host adapter

Private host adapter for the frozen creative source at `../reload-e-zero-creative-sol-r1`. This is not a game connection or native acceptance result.

The renderer uses the shared four-stage WGSL source and `SHADER_ENTRIES` from that frozen creative source. It creates entry-specific auto-layout pipelines for `vsFullscreen` + `fsWorld`, `fsBlurX`, `fsBlurY`, and `fsComposite`; two `rgba16float` MRT attachments feed the separate blur targets, then a premultiplied canvas composite with source factor `one` and destination factor `one-minus-src-alpha`. The 32-float/128-byte plan is packed by the source-owned packer. Each pass owns a separate render target; bind groups are created against each specific pipeline layout and recreated with new target generations.

`planReloadInput(input, planner)` is the only accepted entry to a frame plan. It requires explicit boolean `sourceOn`, `obsOn`, and `mainOn`, plus finite `visibility` in [0,1]; missing values never flow into the creative planner's permissive defaults. Game-clock callers must provide those values from the authoritative game/source/observer snapshot every frame. Do not connect a game-clock plan to the real frame unless these gates and the authoritative geometry/cause have been supplied. The embedded private-gallery fixture uses an explicit pending `start` cause, a separate `complete` cause at 2200 ms, the declared 620 ms complete phase, then source-off for a 700 ms pause before a fresh fixture cause. This is test input, not a guessed game completion. Embedded controls are hidden; standalone mode keeps manual debug controls. First frame is submitted during the active start phase. Game action-reload integration remains unconnected.

Gallery startup messages follow `dva-gallery-startup/v1` and are attempt-bound by token, version id, epoch, sequence, exact parent/origin, and a retire listener. Ready is sent only once after a current 4-pass submission completes and a bounded readback from the emission target finds a finite positive RGB half-float sample. The proof also reports `recorded`, `submitted`, `completed`, canvas connection, pass count, viewport dimensions, and renderer/target generations. A transparent clear alone cannot satisfy ready. Attempt cancellation, device loss, shader/validation errors, and disposal retire work and resources owned by this host.

`?verify=1` permanently hard-zeros the private SFX output through the creative SFX API. The child exposes `window.__gallerySfx.activateFromGesture(item)` for the gallery's same-origin direct-call bridge; it accepts only a nonempty parent-supplied `item.id`, invokes AudioContext creation/resume synchronously in the trusted gesture stack, and returns an `active`/`silent` status promise. The host does not invent the gallery item ID; c409 has no Reload catalog entry pinned yet. The parent bridge remains responsible for exact current iframe/item identity and stale-generation filtering. Without verify, AudioContext is opened only in response to this bridge, fixture button, or canvas gesture; delayed playback rechecks the current cause, phase, source, visibility, and actual elapsed age before requesting PCM. This preview's sound and fixture controls are not game-event or normal-device audio acceptance.

Checks in this directory exercise fake-GPU positive startup, missing-device rejection, shader compile and scoped validation rejection, explicit-gate rejection, 128-byte uniform packing, four-pass record/submit, stale-attempt pre-submit rejection, emission readback positive/empty paths, and startup message retirement. These tests do not compile WGSL on a native GPU and do not establish pixel quality, full lifetime/performance, Safari/iPad, game integration, gallery native replay, publication, or user adoption.
