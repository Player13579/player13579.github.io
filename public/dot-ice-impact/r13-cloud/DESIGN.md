# dot 氷結水 R13 cloud
作者dot。R12限定材質派生。原本不変更、版上限なし、stagingのみ。
AstraのR12実画像では右片離開3〜4pxの床色隙間は達成、これ以上加速せず固定。材質の同面内厚み差が未達のためR13は吸収と基礎散乱へ渡す光路長だけを変更する。
物体固定座標の入射点から、IOR1.31の屈折光線を同じ凸片の全14境界面へ交差させ、最初の正の有限出口を採る。最初の閉形/ reduced motionでは元hull12面のみへ交差、内部切断面で切り上げない。法線とrayは同じ物体座標で正規化。距離不成立時だけ旧近似へ戻す安全境界を持つ。
既存Beer–Lambert吸収とdepthScatterだけを実光路長で評価。旧equal-volume/incidence近似は床のsample offset専用として保持。形状/運動/4片/3〜4px隙間/色/光量/roughness/乳白斑/内部楔/SFX/寿命は不変。新規画像、追加線、粒子なし。これは有限凸体内の一回光路近似で、多重屈折の完全再現ではない。
主判定は1×消灯.4/.75で一つの外面の薄端が床へ抜け、根元が青灰に濁る連続差。通常.16/.4でも同位置、床色隙間不変。単なる全面減光や5×距離maskだけは棄却。全寿命断面と閉形/reducedを独立検査し、連続fps/ブラウザ/音/Safari/本編は未検証扱い。差分制作のB任意規定を適用、独立Astraが実像評価する。
