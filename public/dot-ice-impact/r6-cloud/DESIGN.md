# dot ice R6 cloud
Derivative of R5. Geometry, physics, lifetime, source near-light and audio unchanged. R5 independent GPU review found opaque grey chunks; 97% of body pixels did not react to changed background because transmitted light was a fixed color. R6 renders the actual floor to a separate rgba16float scene texture before ice, and applies a bounded thin-screen refraction offset based on surface normal, IOR 1.31 and approximate equal-volume optical depth. Beer-Lambert absorption now attenuates the sampled scene, with weaker internal scattering and separate Fresnel/specular reflection. This is NOT scene ray tracing, exact exit depth, inter-fragment refraction, or a full glass simulation. No alternate backgrounds are used as aesthetic targets. Native/offscreen and independent visual review pending. Author dot; unadopted; no main-game connection; no listening acceptance; real browser unverified. Not recovered desktop R3/R4.
