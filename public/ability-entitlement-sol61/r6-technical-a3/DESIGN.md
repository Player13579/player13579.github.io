# 能力獲得 R6 — 状態枠への連続記入
追加5版許可は能力獲得のみ。既存R1–R5保存、本版6/10、残り4。品質・採用・公開・ゲーム統合は別判定。
GPT-6.1-SolがVFX/SFXを設計。R5差分改善でありゼロ制作ではない。B差分例外を適用しラスターを生成しない。
成功した新規自己能力権限の同一cause、登録済み人物位置と取得先状態枠だけを使う。アイテム獲得とは独立。
分割面・独立肩形を廃止。単一角丸SDF（半径7 CSS px）に95–520msの斜め記入前線を走らせ、面と輪郭を同じwrittenで制御。520–690msで確定、940–1160msで消える。人物側承認は230msまでその場に留まる。
規則→実装→期待観測：登録位置→rounded/targetD→独立パネルなし。連続性→written共有→同じ進捗。補助→glint3個・軸0.34rad→無効でも主形が読める。低動作→stamp→局所フェード。source OFF/寿命→先頭return→近傍/OBS入力もゼロ。
音はreceipt・記入ノイズ・確定和音。物理的解錠ではない。650ms以降は開始せず、遅延再生はcause経過位置から残りだけ（runtime担当）。
受入：権限cause/重複排除維持、DPR/同一frame登録、実機WGSLコンパイル、自然全寿命と95/430/590/690/1050ms形状、補助分離、source OFF/expiry、GPU排出破棄。CPU検証は画質・聴感の合格を意味しない。
