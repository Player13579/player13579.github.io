# R8 observer and optical candidate decisions

Observer is a declared virtual camera at the registered orthographic target-relative view, with an effective aperture and one parasitic two-reflection pupil image. Choosing it is an explicit artist attribute resolution, not an assumption that the user supplied a real lens. Main world rendering is orthographic; the secondary paraxial reflection relay is an effective sensor mapping with magnification-1.6, ABCD[-1.6,0,0,-.625] determinant1. It is a stylized normalized optical model, not a raytraced measured glass system or an empirical Fresnel validation.

Near glow is selected separately: actual occluded emitted radiance→15tap separable7DPRpixel kernel→gain.34. It supports local source/field brightness and is not called lens flare. Diffraction sparkle is selected as a finite analytic approximation of a four-edge aperture response at the source; all occurrences use the same-31.5° angle. Gaussian arm envelopes approximate the point response and do not claim exact Fraunhofer predictions.

A genuine internal-reflection mechanism candidate is selected provisionally for evaluation: source screen S and observer optical center C determine a pupil image G=C-1.6(S-C). The finite defocused image has7.5×5.25H64 axes and maximum11px support, normalized throughput.065 and relative spectral weights.72/.84/1.08. There is no long ghost train, rainbow requirement or static decoration. Only one focus is strongly active at a time, and its pupil image is governed by actual body/field-occluded sourceSignal. The mapping is outside-near-field enough to be distinguishable from localblur; whether it reads as an optical image rather than a gem atH64 is genuinely unresolved. Ghost addition cannot repair a weak protection shape.

Source0/1 are the actual registered lower/front and upper/front field foci; known hit replaces source0 with the unchanged actual contact. Their power derives from create/hit/break age and owning coverage. World sourceSignal separately records each focus under the same alpha ownership as the world/bright targets. Post samples that sourceSignal at S, so a genuine opaque object suppressing the source suppresses its diffraction/ghost as well. It never relies on source metadata through an invisible body.

Required actual comparisons are samephase combined and each isolated near/cross/ghost OFF; sourceShift[.08,.04] moves actual focus/white patch/point and the optical image; observerCenter[12,-9] moves only the camera optical center with predicted ghost translation2.6*C; sourceOFF removes all owned field/OBS; a visible opaque diagnostic tile covers source0 and its actual radiance/sourceSignal; expiry clears allfield/sources/OBS. The tile is genuine opaque diagnostic geometry after the front pass, not an invisible player/hidden blocker. Each case resets defaults and records the actual submitted phase/flags. Camera center/source controls are diagnostics, not game UI.

No optical or visual pass is claimed by these equations. If actual nativeH64 comparison shows the ghost mimics an independent world object or muddies the protection/receiver, that candidate fails and its scene-specific projection/shape evidence must be retained before a new design decision. Omitting every lens mechanism automatically because the lens was not userdeclared would not be a valid reason.
