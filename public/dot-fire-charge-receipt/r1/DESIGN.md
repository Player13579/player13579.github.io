# ファイアのチャージ獲得 R1「畳まれる熱」

採用済み「ファイア」そのものは攻撃・燃焼の場を描く。一方、ここでは一回分などの数を断定せず、将来使えるチャージを受け取ったことを短く返す。恒久的な能力獲得は新規 entitlement が必要なので別。

既に火色を持つ薄い一枚の葉形が、手元へ巻き込まれながら短い朱の継ぎ目へ畳まれる。継ぎ目は形の一部で、文字、バッジ、星、飛び火、実炎、長い流体尾を追加しない。暗い銅色の開口を中間に残し、発光の先頭が開口の縁に沿って止まる。不動の手元、柔らかい有限の受光と小さい観測ぼけ、顔の遮蔽保護。印象は「閉じ込めた熱」、発射に見える拡散は不可。低減時は葉形をほぼその場で閉じる。規約は現行 B の LDM、空間・時間包絡、体の H64 と単一投影を使用。薄い摩擦音から短い閉じ音を同じ因果で一回だけ鳴らす想定。

正規 `instant-fire-acquired` の `vending` と `mystery-box` だけ。Main/Worker の実装は同じで、失敗、上限、ハッカー生成、他人、発動、恒久解放は対象外。権威イベントにチャージ追加数がないため元件数と無関係に一つの演出。680ms はプレビューの演出尺であり権威イベントのdurationではない。本編未接続・未採用。
