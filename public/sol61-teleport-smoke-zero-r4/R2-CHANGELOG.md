# Teleport ZERO preview r2

This package version replaces the invalidated r1 source seal after review found host authority and frame-serialization defects. The creative kernel is copied byte-for-byte from the frozen design and remains unchanged.

R2 gives ordinary/effect-off frames a neutral actor/floor descriptor without reading a missing E age; keeps the bounded floor fixture as baseline for both endpoints; omits E smoke/flux descriptors for filtered roles; and renders a refused arrival with a grounded, source-disabled actor between visible smoke layers. Flux dispatch, nearby response, shadow modulation, and source emission require the current paired-body ticket. Source-off retains the authorized height stroke while disabling source, flux, nearby, and observer response.

Validation scopes now begin before resource binding and command recording. Their results are observed asynchronously so the render loop does not wait for validation or queue completion. SFX authority is granted only after a successful validation result and a fresh current receipt/scope/owning clock/pose lease check; stale frame results cannot authorize audio. Effect-off, endpoint-filter changes, failures, restart, and disposal revoke the fixture's active voices.

The endpoint control is only a diagnostic filter over the known paired fixture. It is not a canonical private-endpoint intake API. The floor plane is a finite preview fixture, not a game environment. Native WGSL/WebGPU review, continuous visual quality, normal SFX listening, Safari/iPad, gameplay integration, and adoption remain pending.
