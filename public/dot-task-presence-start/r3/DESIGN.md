# タスク端末の待機入り R3（非公開候補）
R1は本人右側に小片が横に開き、R2は右側に離れた二面が降りる。R3は左側の曲がった一枚の縁が同一点を保ったまま画面上方に展開し、停止後に透明になる。待機入りの局所表示で、端末そのもの・操作完了・報酬は描かない。本人の模擬シルエットと背景は比較のため無変更。
- B移行同期版の基底「手続き的描画／検証／比較」、拡張「適用選択／PH・OBS／LDM／実行時E」、DVA開発スキル §4。1枚の短い屈曲面の局所輪郭と時間包絡に限定。R2の同一GPU合成で非発光の暗部を支えに、一縁を翡翠の低い色対比で示す。強いフラッシュ、散粒、速度線、文字、環は追加しない。
- 立ち上がり40–455ms、位置停止、760msから透明へ、1200msでメッシュ0。軽減モードは座標固定で透明度のみ。新規SFXイベントは足さず、R2の同じ音源を再利用。聴感未評価。
- source はR2本人限定の合成再現契約を保持。プレイ中の有効な待機入り、新鮮時刻、未済1件、本人・一般職制約。同一イベントの再現と本編接続は別。採否・公開は未実施。
- CPU plan.test.mjs（状態・所有・値漏洩・有限PCM）、differentiate.mjs（R1/R2の右側とR3左側、固定根元→画面上方、軽減固定、期限）。同条件のSwiftShader fixtureで左右/上下差と期限0画像回帰を確認。正式な親ギャラリー切替は別検証。
