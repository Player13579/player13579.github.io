Creative source is the unsealed GPT-6.1-Sol R11. This runtime is a narrow R10 adapter continuation. The 32-byte tuple, 16-byte View, 16 depth sample ABI metadata, negative main/OBS tags, event validation and sampling, hand/frame-bound endpoint, variant and 900/420 ms activation/beam lifecycle, verify hard mute, reduced-motion behavior, gallery lifecycle and runtime audio remain the settled R10 contract. Exact audio bytes are unchanged.

R11 effect code changes only projected material geometry/surfaces and the WGSL material shader. R11 CPU checks compare sampler byte/semantic parity against R10, CPU literal equations, bounded supports, advective/reduced-motion invariants, role surfaces, return occlusion, and retained strong-white corridor. They do not establish WGSL compilation or GPU pixel parity. No gameplay damage/impact, PostEffects, new bindings, image assets, or audio are invented.
