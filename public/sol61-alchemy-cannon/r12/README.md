# Cannon R12 replay package

This is a private technically replayable package for GPT-6.1-Sol Alchemy Cannon R12. The R12 creative source is an unsealed draft copied byte-for-byte; no design or source edits were made here.

Open runtime-r12/preview/cannon-r12/gallery.html?embed=1&galleryAutoLoop=1. Its four route files are hash-pinned. The original finite-front effect, audio and source contract are under source-r12/.

GPT-6.1-Sol's limited actual native decision is **NOT ACCEPTED** for the required thickness/material criterion. The finite front and connected white face have some fixed-phase support, but the broad blue return/rear body still does not read as sufficient distinct material depth. This is not full-lifetime rejection. See native/QUALITY-DECISION.md and native/CAPTURE-INDEX.json.

The package includes original stable-presented OFF28/100/150/210/220/280/330/390/420 and ON220 JPEG plus their bracketed JSON captures. These are separate held frames, not a continuous animation. ON/OFF at 220 ms share cause/event but have different frame IDs. Full single-cause lifetime, ordinary SFX listening, performance, Safari/iPad/device coverage, parent-gallery replay, game integration and adoption remain unverified or unknown. Verification-mode screenshots were audio-hard-muted; they do not count as ordinary SFX listening.
