# Cannon R10 source and runtime lineage

The creative source is the unsealed GPT-6.1-Sol version alchemy-cannon-new-e-sol61-r10. This package copies source effect, audio, design contract and CPU evidence without modifying the producer folder.

The faithful runtime adapter derives from the settled Cannon R9 runtime. R10 changes only gallery/version identity and exact creative effect/shader pins in main.mjs; the 32-byte tuple, 16-byte View uniform, event/lifetime/OBS behavior, gallery startup lifecycle, renderer, and exact R9 audio implementation are retained. The R9 baseline main/gallery/effect files are included to inspect that derivation. R10 projects three ordered charge sheets; it makes no shader quadrature or depth-integration accuracy claim. The existing CPU steps argument is compatibility-only.

Native evidence is limited to the same cause/frame at 220 ms with source enabled and OBS ON/OFF, plus exact 420 ms expiry after a separate navigation/new fixture lifecycle. Each queue completed with no renderer error. This does not prove an uninterrupted event timeline or full-life quality. Brightness is not the failure. Formal Sol quality decision remains pending.

Normal whole-life motion, ordinary SFX listening, performance, Safari/iPad, game integration and adoption remain unverified.
