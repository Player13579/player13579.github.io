# EC100到達によるMP・SP補充 R1候補「重なる二つの流れ」
v920 Main/Workerでは EC の上限到達ではなく、最高到達値が初めて100に達したときの専用イベント。普通のEC増加、EC500の居合獲得、EC1000、攻撃や既存のリミットブレイクとは違う。長時間の自動補充を再演せず、初回の本人通知のみ。MP・SPの補充を主題にして、HPやバリアの表示・量・永続保証・数値は描かない。
二層の薄い帯が体の左右に分離した状態から始まり、腰近くの同じ高さで左右の奥行きの違う面へ一度だけ収まる。流れを人体に貫通させず、中央は身体の輪郭として抜く。持続するオーラ、アイコン、星形光条、無限大記号は使わない。短い二帯域の音を同じ定着に同期し一回鳴らす。720msは鑑賞版の設計値でありゲームの能力期間を示さない。
