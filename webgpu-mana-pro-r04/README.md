# DVA マナ獲得 E r0.4 — 外流・境界変換・輪郭充填

**提出候補／品質採否保留（Warning）。実GPU・実聴・本編接続は未承認です。**

権威確定した正のマナ増加を、受益者の身体への獲得として描く、独立した手続き型WebGPU／SFXパッケージです。今回の実装・造形・音は新規作成です。旧版ZIP、旧Sol/Astra、他Eの画像・音・コードは読まず、提示されたイベント契約とr0.2／r0.3の失敗報告だけを改稿入力にしました。

## 起動

Node.js 20以上で、このフォルダー内から **`npm start`** を実行し、**`http://localhost:4184`** を開きます。`npm install`、ビルド、外部CDN、ゲームリポジトリは不要です。別ポートは `node tools/server.mjs 4188`。`file://` 直開きではなく同梱サーバーを使ってください。

ブラウザーがWebGPUを提供しない場合や原本WGSLのコンパイルに失敗した場合は、画面にエラーを出して停止します。CPU画像への自動代替や、WGSLの自動書き換えはしません。音は「音を有効化」の操作後、新しい原因から鳴ります。初回は小さめの音量で確認してください。

## 今回変えた因果

外側には、太さと位相の異なる二つの有限なエネルギー帯があります。帯の本体は身体の受容ポリゴンから切り抜かれ、**元の形のまま身体内へ移動しません**。境界を通過する量から局所的な変換光を計算し、同じ受領量で身体形状内の充填面積を求めます。

中心に別の楕円・紋章・種・小物を置く構成ではありません。定着は既存身体面の応答として保持します。終盤に減るのは発光と可視coverageであり、獲得済みマナの値ではありません。VFXはゲームのマナ値を操作しません。

強い放射源、有色本体、暗い溝、境界接触光、身体面の光応答を分離しています。観測側では発光入力だけに局所bloomを適用し、HDRの高いピークだけを表示範囲へ圧縮します。背景色を見て形・色・強度を切り替えません。

## プレビューで確認できるもの

同じWGSLをH64実寸、H128、H192の暗／明6画面へ描画します。H64は64 CSS pxで、DPRは描画バッファの密度だけに関わります。単発／近接3原因（0・160・320 actor-ms）、通常／2倍actor時相、1500／900 actor-ms、前景遮蔽、層の分離、局所bloomの有無、無音スクラブを切り替えられます。

自然再生は消去後の空白まで含む自動ループです。次のループは新しい原因IDを持ちます。同一原因の再通知、死亡・退室・ベント・透明化・セッション切替、身体のみの復帰も検査できます。音声要求数とAudioWorklet実行カウンターは分けて表示します。6画面を描くために6声を鳴らしません。

## 検査

`npm test` は実行ロジックとGPU記述モックのテストです。`npm run lint` はNode構文検査とWGSLの局所字句検査、`npm run design` はB設計の局所構造・参照照合です。**WGSLコンパイラー、公式B検証器、画質の採点器ではありません。**

`npm run verify` は配布manifestと内容・ファイル一覧を照合します。`npm run check` は上記をまとめて行います。通常検査は配布ファイルを書き換えません。ログ記録・再生成コマンドは `docs/TESTING.md` を参照してください。

実GPU確認では、この環境のChromiumがlocalhostへのナビゲーションを `net::ERR_BLOCKED_BY_ADMINISTRATOR` で拒否しました。原本のWGSL読込前に停止したため、**ネイティブWGSLコンパイル、実GPU全寿命、AudioWorklet実稼働、実聴は `not_run`** です。CPU診断資料・数値テストで代替合格にしていません。

## ハッシュ

`npm run verify` が全ペイロードを検査します。manifest自身のハッシュを同じmanifestへ入れると自己参照になるため、manifestだけを内部一覧から除きます。manifestも含むZIP全体のSHA-256は提出メッセージに別掲します。内容を編集・再生成した後の独自版には `npm run manifest` で新しいmanifestを作成してください。

ゲーム採用、実スキンでの受容マスク、場面間遮蔽、実機フレーム時間、ミキサー音量、本編イベント接続の承認は別審査です。
