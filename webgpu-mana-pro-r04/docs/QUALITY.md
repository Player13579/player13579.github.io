# 品質・検証記録 / r0.4

## 採否

**候補を提出。品質採否は保留／Warning。本編接続は未承認です。**

コードの状態・幾何・数値・構造の局所テストは、実GPUでの知覚や音の実聴とは別です。`GlobalAcceptanceTemplate` のRenderObservationとOutcomeEvaluationは `not_run`、FinalStatus.render_statusは `NotRun` のままです。

## 報告された旧版の観察範囲

r0.3はユーザー環境のChrome実WebGPUで、原本WGSLの三項演算子を同義selectへ変換する技術adapterを経て再生されました。H64／2倍／3倍で胴内の緑青の平坦な楕円に見え、身体外の供給→受容・充填が読めず品質不合格という報告です。**これを旧版の全寿命・実聴・実ゲーム確認済みと拡大解釈しません。**

r0.4制作では旧版のコード・画像・音を読まず、この報告とゲーム契約を課題として新しく設計しました。旧版GPU画像との統制された比較実験は実施していません。

## 原本の構文と実行可能性

原本の `mana.wgsl`, `post.wgsl`, `preview/fixture.wgsl` にはWGSLにない三項演算子を使用していません。局所字句検査でコメントを除いたquestion-mark、JS/GLSLの混入、予約語、区切り、入口名を検査し、Nodeは実JS／MJS構文を検査します。**この検査だけでWGSLの型・uniformity・driver適合を証明したとはしません。**

ブラウザー起動時には原本テキストをそのまま `createShaderModule` に渡し、`getCompilationInfo` と非同期pipeline生成、validation error scopeを通します。原本ハッシュも記録します。コンパイル回避のソース改変・CPU代替・エラー無視は行いません。

今回の実環境では、Chromium 144.0.7559.96がこのr0.4サーバーへのナビゲーションを `net::ERR_BLOCKED_BY_ADMINISTRATOR` で拒否しました。HTTP配信とブラウザーpolicyは別の検査です。実WGSLのロード／ネイティブコンパイル前に停止しており、WGSL欠陥だと推定することも、ネイティブコンパイル通過だと記録することもしません。`qa/browser-run.json` と `qa/browser-attempt.txt` に実際の停止理由を保存しています。企業policyやGPUbackendの強制変更はしていません。

## not_run

ネイティブWGSLコンパイル、GPU hardwareの実描画、H64全寿命の実GPUレビュー、AudioWorklet実稼働、音響機器の出音、実聴、実DVA配線・実スキン・performance計測は `not_run`。CPU資料とoffline WAVで補完合格にしません。

## CPUで分かったこと／分からないこと

今回のCPU資料では、供給帯が身体外にあり、接点と身体面の充填が独立した領域として見えます。外側が縮退した後も、別の楕円を生成せず身体面が余韻を持つことを確認しました。これは自作CPU近似画像の所見です。

供給帯が刃・弾・羽根に見える可能性、充填面が服の着色やUIバーに見える可能性、低明度終端が明背景で弱くなる可能性、3原因が重なったときの接点や受容前線の識別は未解決のGPU／知覚検査課題です。境界での可視消費がマナ獲得として一目で理解されるかは、数値の面積一致では判定できません。

## 採用前の受入条件

1. H64・説明なしの連続再生で外側供給、境界通過、内部変化を区別できる。外側の物体が同じ形で胴内へ入る印象、内部の独立楕円・UIへの誤読が残らない。
2. 暗／明背景に同じsource設定を使い、有色本体、暗い溝、局所強放射を読める。背景色による強度切替や一律減光で成立させない。
3. 充填量と外側の消費が時間上で対応し、定着後は蓄積状態を保って光だけが消える。1500ms終了とその後の空白まで観察する。
4. 背面→身体→前面→前景の遮蔽が一貫する。実スキンのポリゴン・関節・現在poseにも対応し、顔や重要接点を不要に潰さない。
5. 1／2倍actor時相、900／1500ms、単発／近接3原因で同じ因果が成立する。3原因に3声、同原因配送重複には追加の声なし。
6. 実聴で起音、変調から定着への収束、終端の低音量を確認する。rate変化、pause、取消しで不快なクリック・誤発音がないか聴く。
7. 任意相からの死亡・退室・ベント・透明化・セッション変更で残留を消す。身体を戻しただけでは復活しない。

一場面・一枚の成功で普遍的品質を宣言しません。CPU資料数や構造チェック数を芸術性の得点へ変換しません。
