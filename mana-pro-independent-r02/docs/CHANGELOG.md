# r0.2 変更記録

## 造形・位相を再設計

供給面、太い連続輸送面、下から上へ増える受領面へ変更。輸送を一つの移動核ではなく前端/後端を持つ面とし、前端到着→充填開始、供給終了→後端回収、満量→保持→収束を同じPHASEに記述。受領の収束時は光域も縮む。

これはr0.1の特定パラメータの不具合を特定したという変更記録ではない。r0.1の原因は未特定。

## 継承したもの

確定通知のallowlist/除外、IDとepoch、OwnerClock、可視receiptによる一回限り音、抑制/破棄の基本契約、1.6所有者秒を継承。SFXの自作合成構造を新PHASEへ同期してWAVを再生成。r0.1の実ゲーム外の候補から継承したのであり、実ゲームのMana実装を取り込んでいない。

## 検査・プレビュー

案内なしH64を既定にし、無音の層分解とOBS/受光なしの検査を追加。模擬イベントの遅延callbackをsessionへ束縛して切替/非表示/スクラブで破棄。DOMで部分的に切れたcanvasは安全側に非表示扱い。

r0.1の83テストのうち造形仕様が変わった2件（到着点/軽減モーションの詳細）だけ期待する幾何契約を更新。他のイベント・時計・発音の期待値を維持。新しい解析場テスト18件と、DOM可視性mock・梱包/参照のテスト12件を追加（計113件）。実GPU・聴感はnot_runのまま、CPU検査の成功とは分離。

## 非変更範囲

ゲームソース、公開サイト、GitHubブランチ、ゲーム状態、mana付与処理は変更していない。本ZIPはローカルの独立候補だけ。
