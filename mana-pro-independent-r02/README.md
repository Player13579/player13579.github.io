# Defenders vs Attackers — 独立Mana r0.2

**源から、受領へ。** 通常の正の離散マナ獲得だけを対象にした、WebGPU実行コードのギャラリー候補です。画像生成物ではなく、ゲームや公開サイトにも導入していません。

## この版について

r0.1についてユーザーから「Chrome WebGPUでH64実寸・暗明両背景・全寿命の技術再生は成功したが、中央の小さな六角発光体が主に見え、源→輸送→蓄積を一目で読めない」と報告されています。**原因は未特定**です。その観察を棄却基準に置き、特定パラメータの責任とは決めつけず、供給面・連続輸送面・充填される受領面へ作り直しました。

r0.2の納品時点では実GPUコンパイル・実画素・実時間の動き・聴感は **not_run** でした。作成環境のChromiumがローカルページへの移動を `ERR_BLOCKED_BY_ADMINISTRATOR` で拒否し、GPU検査へ到達していません。Nodeの契約テスト、CPU参照場の面積・接続、構造・参照検査は別に収録しました。これらを品質合格、r0.1からの改善実証、実ゲーム統合と呼びません。

Codexによる2026-09-28の後続検査では、Windows Chrome WebGPUのシェーダー生成・161位相の画素代理検査がpassしました。一方、暗明H64原寸の全寿命では源から腹部への連続輸送と受領側の蓄積を説明なしに読み取れず、**視覚品質は不合格**です。支配原因は未確定、聴感と実ゲーム統合はnot_run。元のPro納品物は別に保全し、この公開コピーにはギャラリー自動再生adapterを追加しています。

## 起動

このREADMEのあるフォルダーで `npm start` を実行し、表示された `http://127.0.0.1:8765` を開きます。Node.js 20以上を使用してください。依存パッケージのインストールは不要です。Windowsでは `START-Windows.bat`、macOS/Linuxでは `START-macOS-Linux.command` からも起動できます。

プレビューは **H64、ブラウザー倍率100%、初期無音、位相案内なし** です。暗/明を横に並べ、一件の同じEを表示します。二つの背景表示のために音を二回発音しません。キャラクター・代用人形は描きません。

「正の獲得 +4」を再生し、必要に応じて全寿命の反復、近接三件、1×→2×→1×の切替を使います。音は明示的に有効化した後の、新しい可視イベントからだけ鳴ります。スクラブ/層分解は無音の検査用であり、正規イベントではありません。

H128や3倍表示、位相の案内、層分解、CPU参照像は補助です。これらでしか因果が分からない場合、H64原寸の受入を通したことにはなりません。

## 造形の変更

| 領域 | r0.2の採用実装 | H64で狙う読み |
|---|---|---|
| 足元の源 | 最大86×26wuの充実した琥珀色の供給面。量とともに面積を減らす | 小さい光点ではなく、供給の所在と減少 |
| 輸送 | 全幅23〜28wuの曲がった連続面。前端が先に到着し、供給終了後に後端を回収 | 点列ではなく、源と受領先のつながり |
| 腹部位置の受領 | 高さ8→44wu、半幅22→34wuへ充填。上端が上がり、満量を保持して収束 | 到着に対応する面積・残量の増加 |
| 光・観測 | 現在のPHに結んだ有限入射光と狭いOBS拡散。収束時は光域も縮める | 主形を隠さず、局所発光と周辺光を区別 |

これらは設計値です。実寸でその意図が伝わったという測定結果ではありません。実際の人物・材質・深度との合成は未接続です。

## 変更していない契約

実行時のduration正本は `src/contract.mjs:EFFECT_DURATION_SECONDS = 1.6`、単位は所有者秒です。視覚・消失・SFXは同じPHASEを使用します。移動ACC2が実際にactiveかつ有効な間だけ2倍速で、待機・予約・OFF・非移動は1倍速。途中切替は区分積分し、視覚もBufferSourceの位置も巻き戻しません。2倍速では音高も上がります。

一件の確定済み正の離散増加、同じ受け手playerId、一意のevent idだけを受理します。map-object/normal と mystery/mana-surge が対象です。0/負値/上限での無変化、自然回復、同じIDの再受信、desire-recovery/renki/renki-tenfold は除外します。死亡・退場・ベント・透明・別context・失効・画面外/非表示は抑制します。ゲームマナの付与や状態の書き込みは行いません。

SFXは同じIDの、成功した可視WebGPU提出・主形のtoken readback・再検査が揃った最初の一回にだけ結びます。ミュート、verify、非表示、AudioContext非runningのときは鳴らさず、後から補発音しません。ルーム/セッション変更で旧E・音・台帳・世代を破棄します。主な入口は `src/index.mjs`、入力仕様とホスト責務は `docs/INTEGRATION.md` です。

## 検査コマンド

| コマンド | 検査対象 |
|---|---|
| `npm test` | 契約・時計・発音mock・波形・CPU形状。実GPU/聴感は含めない |
| `npm run test:syntax` | JavaScriptの構文 |
| `npm run design:check` | Bインスタンスのローカル構造・参照・実装symbol。公式B検証器ではない |
| `npm run test:cpu` | 161位相の解析場の接続・面積・OBSなしの主形。GPUではない |
| `npm run test:hashes` | 配布物のSHA-256照合 |
| `npm run sfx:build` | 固有WAVを共通PHASEから再生成し、数値検査 |
| `npm run preview:reference` | CPU参照PNGを再生成。プレビューはこのPNGを読み込まない |

実GPU検査はプレビューから `tests/verify.html` を開いて実行します。161の固定位相と層分解を読み戻す技術検査であり、正常なrAF全寿命再生と人による意味読解も別途必要です。結果JSONを保存できます。自動実行用の `tests/gpu_probe.py` はPlaywright/Chromiumが別途ある検査端末向けで、通常のプレビューには不要です。

ハッシュは**再生成前の配布物**に対して確認してください。証拠ファイルを再生成すると、そのファイルのhashが変わることがあります。意図的に再配布する際だけ `npm run build:manifest` で一覧を更新します。

## 範囲と限界

通常ランタイムはWebGPUのみです。Canvas 2D/WebGL fallback、画像テクスチャ素材、外部CDNを使いません。GPU中間render targetは使用します。CPU参照モジュールとPNGは検査専用で、プレビューの描画代替ではありません。

部分的にviewport/祖先のoverflow領域から切れたcanvasは安全側に非表示扱いにします。HTMLによる任意の被覆、実ゲームの遮蔽、身体材質、音響デバイスの遅延は、この独立候補だけでは完全には検証できません。ホストは可視性・状態変更・ACC2実効切替を直ちに通知する必要があります。

同時上限64件、セッション台帳100,000 ID、容量超過はfail-closed。数値・構造のPassと、H64意味読解・聴感の受入を分けてください。**本版は未受入の候補です。**
