# r0.8 gates

## Principle
Code success is not visual acceptance.

## H64 reject conditions
Reject if any one occurs:
1. the effect reads mainly as a flat emblem instead of a volume around a receiver
2. the center airspace is visually filled during create or absorb representative times
3. front plane / rear plane / depth relation are not inferable
4. absorb does not show a local intercept state and internal propagation
5. fracture is not distinct from bust in both shape and time logic
6. visible intensity depends mainly on generic bloom / particles rather than structural sources
7. light-background readability collapses

## Representative times
- create: 300 ms
- absorb: 175 ms
- fracture: 240 ms
- bust: 240 ms

## Support checks only
- H64 create/absorb center `receiverAirspaceFilled == false` in dark and light previews
- finite numeric outputs
- `release-status.json` remains `not_run` for real GPU / real audio / final quality
