# 拡張の起動範囲

VFX、LDM、ECodeImplementation、PH1の強い放射を入力とする局所PSFのPostEffectsを起動する。PostEffectsはattribute_resolved、ordinary_posteffects=false、選択操作OBS2だけを出力する。

KeywordExpansionは登録されたexact keywordをユーザーが選択していないので無効。MagicArchitectureは魔法/明示別名の選択が無いので無効。武器名からプリセットを選ばない。

CharacterPolicy/BeautifulPoseCapsuleは、このEが人間/キャラクター身体を新規生成・再作画しないため対象外。playerId/targetIdは既存実体への参照であり、その外見・年齢・人数や姿勢を決めるものではない。プレビューの受光面は検査fixtureで、キャラクター/頭蓋/傷を仮定しない。

VideoGenerationPolicyは映像モデル用のMode=Videoではなく、Eソースの実時間処理であるため無効。B設計の代表ImageとEの連続時間契約を区別する。勝手な10秒のクリップ尺を設けない。

GradientAnchorPolicyは色相アンカー間のグラデーションを選択していないため無効。有色面/源/受光/SDR飽和による色の見えの違いを、義務的な虹色グラデーションへ読み替えない。

Fire/Water/Cloth/Metal/BodySkin/ReactivePhaseChange等は該当する実過程や新規実物質が無いため起動しない。必要な光応答はPH1/PH2の全領域欄に、適用と非適用の理由を記述する。

レンズghost/veil/streakは実際のレンズ経路を選択していないため描かない。源の強さだけから全光学アーティファクトを一括発生させない。源に束縛された表示PSFはOBS2で実装し、lens flareだと偽らない。
