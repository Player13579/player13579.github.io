# Headshot Contact E / v5

**全武器・HIP/AIMに共通する、一つの新しいWebGPU VFX＋一回限りSFXです。**

10種類を見分ける条件は撤回されています。variantは正規イベントの検証にだけ使い、形・色・寿命・音色・乱数に渡しません。旧v1–v4から参照した本文はイベントゲート、時計、イベント契約、基底出典識別子の4件だけです。旧幾何・shader・造形・色・時間設計・SFX・テクスチャは新案の入力にしていません。

## 起動

Node.js 20以上で、このREADMEのあるフォルダーから **`npm run serve`** を実行し、表示される **`http://127.0.0.1:8795/`** をWebGPU対応ブラウザーで開きます。ランタイムの依存インストールは不要です。file://ではなくローカルHTTPを使用してください。

ページは初期化後、単一Eを新しいfixture IDで自動ループします。H64/H32の暗明4面と320px拡大は、同じframe・同じIDの観測です。観測先を増やしても発音は増えません。音声は「音声を有効化」を押した後の新規IDからのみ再生し、過去の音をキューに溜めません。

`PORT`環境変数でポートを変更できます。macOS/Linux例は `PORT=8080 npm run serve`、PowerShell例は `$env:PORT=8080; npm run serve` です。

## 新規の形と音

固定接触点の小さな核が強く立ち上がり、ひと続きの厚い圧縮膜が遅れて展開します。膜の不等な曲率と内側の返り襞が、起点の周りで一度だけ進み、560msで消えます。連続面の内部構造であり、飛翔片、弾道、組織の変形や傷ではありません。

核、膜、既存面受光、源に束縛された局所PSFを分離しています。**白飛び回避のauto-exposure、tone shoulder、合成輝度上限、減光gainはありません。** 線形HDR値を加算し、SDR格納時の飽和をそのまま許容します。現在の可視性・遮蔽・保護maskによる出力抑止は、露光制御ではありません。

新しい210msの単一SFXは、短い接触クリック、丸い胴、拡散尾を手続き合成します。銃声や旧音源を重ねません。音の安全な振幅/同時voice制御は視覚の白飛びとは別です。

## 技術契約

入力は `type=action-gunner-headshot`、固有`id`、`playerId`（射手）、`targetId`（既存対象）、固定`x/y`、`radius=150`、10通りの`variant`、正規化後の`atMs`です。`atMs`はこのパッケージのキー名で、実サーバーの未知の時刻キーを推測していません。

ホストの`verifyCanonical`と`getPermission`が必須です。ページのWeakMap台帳はテスト用で、本番認証の実装ではありません。正規headshot抽選をクライアントで推定せず、`action-shoot`と時刻近接による一対一対応を作りません。ペネトレイトの別着弾は別イベントとして残します。

不可視化、対象世代変更、部屋変更、期限切れ、時計逆行、重複で旧Eを再開しません。死亡・ダメージ・出血・破壊・スタッガー・反撃停止を描画/書換えするAPIはありません。詳細は `docs/EVENT_CONTRACT.md` にあります。

## 検査と証拠

- `npm test`：イベント/時計/音の一回性/共通出力/幾何/プレビューのNode検査。
- `npm run check`：B設計の構造、参照、JS構文。GPUや芸術性の合格にはしません。
- `npm run evidence:cpu`：単一Eの通常/reduced全寿命と、10入力の同一状態を数値記録。
- `npm run build:sfx`：新しい共通WAVを再生成。
- `npm run test:browser`：Python Playwright＋Chrome/Chromiumで実GPU取得を試行。Playwrightは別途必要で、runtimeの依存ではありません。
- `npm run verify:manifest`：ZIP展開後の全ファイルのSHA-256照合。

ページの「ライブ提出をZIP保存」は次の自動提出をreadbackします。「単一Eの全寿命をZIP保存」は通常/reduced × H64/H32 × 暗明、各61時点の8枚の実画素シートとJSONを保存します。各シートは左から右、上から下へu=0/60…60/60で、残り3セルは未使用です。

入力同一性の検査は10種の見分けや芸術性評価ではなく、**10入力が同じ出力になる**ことの技術検査です。白く飽和した画素数も記録しますが、それ自体を不合格にはしません。

## 検証状態

納品時の実施結果は `evidence/acceptance.json` と `docs/ACCEPTANCE.md` が正本です。通常Chromiumのページ読み込みは今回 `ERR_BLOCKED_BY_ADMINISTRATOR` で停止しました。実WGSLコンパイル・GPU画素・ブラウザー連続再生・OfflineAudioContext・実音声出力・聴感は **not_run** です。内部のCPU近似図やNode検査を実GPU証拠にしていません。

提出追従時計は原寸で全寿命を観察しやすくする検査専用条件です。1提出の進行を最大16.667msに制限するため、低速環境では実時間より遅くなります。制限量をUIと証拠に表示し、性能合格とは主張しません。低速描画時の実音声との同期は別途聴感検査が必要です。

## 構成

`src/`：完全な実行モジュールと型定義。`shaders/`：新規WGSL。`preview/`：独立自動ループ/証拠取得。`sfx/contact-common.wav`：唯一の音素材。`design/b-design.json`：B基底と起動拡張の完成設計。`foundation/`：固定出典と91適用規則の対応。`sources.json`：創作・技術出典の範囲。`FILES.sha256`：自己を除く全ファイルのハッシュ。

v1–v4は変更していません。ゲーム本編・ギャラリーへは接続していません。
