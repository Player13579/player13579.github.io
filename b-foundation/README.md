# B 制作ギャラリー

公開先: https://player13579.github.io/b-foundation/

制作するユーザーがぜひ知っておくべき、このチャットで実施した改善だけを掲載する。知らなくても制作に支障がない内部仕様・検査・計算方法の記録や、他のチャットによる改善は展示しない。制作向けの見出しへ言い換えるだけで掲載対象にせず、具体的に知る必要性を説明できない項目は外す。

日付や作業順で分けず、一つのページにまとめる。掲載基準を満たす内容がなければ `items` は空のままにし、仮の作例や報告で埋めない。仕様・検証・作者の履歴は元のリポジトリや作業記録に保持し、ギャラリーに転載しない。

## 更新方法

1. 掲載基準と、このチャット自身の変更である根拠を確認する。
2. 掲載正本 `gallery.json` を更新する。トップレベルは `title`、`intro`、`items`。各項目は一意の `id`、`title`、`benefit`、`how_to_use`、`principle`、`evidence` を持つ。必要な実例画像だけ `image` と `image_alt` の組で添え、画像は安全なローカル `assets/` パスへ置く。
3. `python -X utf8 b-foundation/tools/build.py` で `index.html` を生成する。生成HTMLを直接編集しない。
4. 内容・リンク・画像・実表示を確認し、このディレクトリの必要な変更だけをcommit・pushする。
5. GitHub Pagesで対象commitの公開成功と、公開ページ・媒体の内容を確認する。実生成や実観察をしていない効果は、確認済みと書かない。
