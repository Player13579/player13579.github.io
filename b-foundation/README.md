# B 制作ギャラリー

公開先: https://player13579.github.io/b-foundation/

このチャットで行った改善を、一つの見出し一覧から読む。本文は記事を選ぶまで閉じ、モード切替や日別ページは設けない。現行一覧はこのチャットの全報告を対象とし、掲載範囲に新しい指定があれば従う。

見出しと要約は、制作で何ができるようになるかを示す。「道具・ツールを追加した」を成果の主語にせず、「〜する機能を追加した」と具体的な能力を書く。補助UIや保存経路は必要な場合の説明に留め、内部改善を制作便益や未確認の美的効果へ言い換えない。

他のチャットが独立して実施した改善は含めない。このチャットの指示下で採用したサブエージェントの貢献は含め、過去の作者帰属と検証証拠を保持する。

## 更新方法

1. このチャット自身の変更である根拠と完了状態を確認する。学問分野、具体的な原理・法則と今回の利用、根拠、適用範囲を結ぶ。
2. 掲載正本gallery.jsonを更新する。title、intro、items、各id/title/summary/principle/evidenceを保持する。essential/show_headingは過去の掲載判断の来歴として残るが、現在の表示フィルターやモードでは使わない。
3. 必要な参考文献、GitHub commit、実例画像、補助表示へのリンクを付けられる。実生成画像、説明図、構造検査、美的効果の実証を区別する。
4. python -X utf8 b-foundation/tools/build.pyでindex.htmlを生成する。生成HTMLを直接編集しない。
5. 初期状態で見出しだけが並ぶこと、本文の開閉、キーボード、直接リンク、補助表示から戻る操作、390px幅の実表示を確認する。gallery-articles.jsはURLのhashに対応する記事を開く。旧?view=all等のqueryは表示を切り替えない。
6. 必要な変更だけcommit/pushし、GitHub Pagesの対象commitと公開本文・媒体の実bytesを照合する。
