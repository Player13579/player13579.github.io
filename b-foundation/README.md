# B 制作ギャラリー

公開先: https://player13579.github.io/b-foundation/

同じ一つのページを二つのモードで読む。日別のページや一覧には分けない。

- **制作に必要な内容**（通常表示）: ユーザーが制作する上でぜひ知っておくべき、このチャットの改善だけを展示する。知らなくても制作に支障がない内部仕様・検査・整合性修正や、制作上のメリットが感じにくい方法論は含めない。制作向けの見出しへ言い換えるだけで掲載基準を満たしたことにしない。該当がなければ空の状態を保つ。
- **すべての報告**: このチャットが実施した改善の報告を、内部仕様・検査・方法論も含めて読む。過去の報告とその後の完了した改善をまとめ、作業ログの逐語転載や同じ成果の重複掲載はしない。

どちらのモードにも、他のチャットや別担当が独立して実施した改善は含めない。このチャットの指示下で採用したサブエージェントの貢献は含め、過去の作者帰属を保持する。報告原本と検証証拠は元リポジトリや作業記録へ残す。説明図、構造検査、実生成画像と美的効果の確認を区別する。

## 更新方法

1. このチャット自身の変更である根拠と完了状態を確認する。通常表示への掲載は制作上の必要性を別に判断する。
2. 掲載正本 `gallery.json` を更新する。トップレベルは `title`、`intro`、`items`。各項目は一意の `id`、`title`、`summary`、`principle`、`evidence`、真偽値 `essential` を持つ。`essential: true` の項目は `benefit` と `how_to_use` も持つ。通常表示はこの項目だけ、全報告表示は全項目を表示する。
3. 任意の `example`、HTTPSの参照文献 `references`、GitHub commitへの `source_url` を付けられる。必要な実例画像だけ `image` と `image_alt` の組で添え、画像は安全なローカル `assets/` パスへ置く。存在しない作例や未確認の制作効果を補わない。
4. `python -X utf8 b-foundation/tools/build.py` で `index.html` を生成する。生成HTMLを直接編集しない。
5. 両モードの内容・切替・直接リンク・戻る操作、リンク・画像・実表示を確認し、このディレクトリの必要な変更だけをcommit・pushする。
6. GitHub Pagesで対象commitの公開成功と、公開ページ・媒体の内容を確認する。実生成や実観察をしていない効果は、確認済みと書かない。

`?view=all` は全報告へ直接開くリンク、`?view=essential` または指定なしは通常表示。選択を端末へ保存して全報告を次回の通常表示へ変えない。
