# r0.7 gates

## Core rule
Passing code, hashes, WGSL compilation, or numeric tests does not equal visual acceptance.

## H64 reject conditions
Reject if any one occurs:
1. effect reads mainly as a physical object instead of a held digital field
2. protected airspace is visually filled at create/absorb representative times
3. front and rear planes are not inferable
4. action point is not readable in absorb
5. fracture and bust are not causally distinguishable
6. bright response depends mainly on generic bloom/particles rather than structural sources
7. light-background readability collapses

## H64 representative reads
- create 300 ms: nearly assembled digital field with open airspace
- absorb 175 ms: same field plus readable right-side impact locus and dent
- fracture 240 ms: diagonal tear and shear
- bust 240 ms: orderly deauthorization split, distinct from tear

## H100 representative reads
Same as H64, with stronger front/rear depth and source placement.

## Quantitative support checks
These are support checks only, not final proof:
- center `receiverAirspaceFilled` should be false for create/absorb H64 dark/light representative probes
- no NaN / invalid channel values
- real GPU and audio acceptance remain `not_run`
