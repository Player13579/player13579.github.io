# 創作入力・凍結範囲・確認履歴

対象は提供されたEMP-E r0.1配布物の品質改稿です。独立案r0.1の自作ソースを改稿の基礎とし、今回の5枝・保持/終端・デジタル情報場の追加指示を創作入力にしました。旧Sol/Astraの画像、造形、配色、層、演出時刻、音源、コードは調査・流用していません。旧版比較画像をWeb検索することもしていません。

r0.1の公開API資料とcontract値はイベント境界の確認に使用しました。そこに存在したpairResult/classifyResonance/normalHitはarchive/r0.1-contract.jsに履歴保存しますが、r0.3の外部API・rendererはimportも公開もしません。現在のサーバー原本は提供されていないため、サーバー実装の全契約を確認したとはしていません。

B設計の汎用的な構造欄とローカルvalidator/manifest/asset-checkは当該独立r0.1の既存構造を保ち、r0.3の情報場・保持・権威終端・sampler/画面統合へ更新しました。参照した外部Web情報はWGSL/WebGPU/Web Audioの技術文書だけで、美術入力ではありません。

## P0

gallery/r0.1-p0/ の全ファイルは、受領したr0.1の同一パスとバイト比較した凍結版です。内部ソース・チェックポイント文言・元UIを品質改稿用に書き換えていません。外側のgallery/index.htmlで凍結ブロックアウトと明示し、r0.3から区別しました。quality/p0-frozen.jsonにファイル別SHA-256と比較結果を記録します。

ユーザーから報告されたP0の確認範囲は共鳴0.70 actor秒のみ。r0.1の確認範囲は通常転送と共鳴の限定状態。これを全5枝・全寿命・明暗・実聴の証拠に拡張していません。

archive/r0.1-report-as-received.json は旧配布の報告をそのまま隔離した履歴です。r0.3の合格証ではなく、現在の提出結果はquality/report.jsonです。

## 非主張

新しいr0.3の実GPU・実聴・実H64評価、r0.1に対する実画像品質の優越、実サーバー接続の正当性を実証済みとはしていません。ファイル一式の実装と静的/数値検査が存在することと、実描画・音響の品質承認は別です。
