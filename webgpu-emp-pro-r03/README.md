# EMP E r0.3 — Phase Interlock / 位相演算場

**r0.2の実WebGPU観察で指摘された弱点を受け、主形・内部構造・受け手応答を再設計した品質改稿版です。実GPU／実聴／知覚品質の最終承認は未取得。本編接続は未承認。**

チャージ、通常放出、同位相共鳴、逆位相相殺、対象ストレージロックの5枝を改稿した、依存ライブラリなしのWebGPU / Web Audio資産です。専用画像テクスチャ、外部CDN、ダウンロード時の追加音源は使いません。HDR/depth render-target texture は GPU の作業領域としてのみ使用します。

## r0.3 の改稿焦点

r0.2のChrome実WebGPU確認では、**通常放出が細い平行シアン線の印象に留まり、相殺が細い縦線の消滅に近く、共鳴の共有ハブの局所強輝度と照射・暗部抑揚が不足**していました。r0.3では以下を改稿しました。

- **通常放出**：発動者側の読出しゲート、有限長の搬送胴体、進行packet、対象到達時の局所クランプと近傍応答を追加し、輸送と受け手をH64で読めるよう再構成。
- **同位相共鳴**：共有ハブを厚い暗部本体＋三段共有スパイン＋六放射の結合路へ強化し、最強輝度が中点に集まり、周辺応答が因果接続されるよう改稿。
- **逆位相相殺**：左右の補対列を、中央のnull trenchへ噛み合って消去される広い楔列へ変更し、移動する消去前線と残存構造の同時存在をH64で読めるよう改稿。
- **チャージ／ロック再監査**：寿命全体の保持・終端・延長非再起音の状態契約は維持し、主形の補助リブのみ追加。r0.2と同じ権威契約を保持。

デジタル性は `src/information-state.js` が制御する**捕獲・占有・共有接続・補対消去・書込禁止**の主構造から生じます。格子／走査線／大量粒子／全面bloomを足してデジタルに見せる方式ではありません。白い強芯は狭い稜線に許しつつ、暗い面・空隙・境界を残します。局所フレア／ブルーム等の観測応答は、明るい稜線・発光面に由来する post-process のみで、世界内の主形と切り離しません。

## 起動

ZIPを一つのフォルダへ展開し、Windowsでは `START-Windows.cmd`、macOSでは `START-macOS.command`、Linuxでは `START-Linux.sh` を実行します。Node.js 18以上が必要です。実行許可が付かない環境では、フォルダ内で `npm start` を実行してください。`npm install` は不要です。表示されたローカルURL（既定 `http://localhost:8080`）を WebGPU 対応ブラウザで開きます。`file://` で HTML を直接開く起動方式ではありません。

サーバーは `127.0.0.1` だけで待ち受けます。既定ポートが使用中なら環境変数 `PORT` を変更してください。ブラウザ本体・GPUドライバー・Node.jsを同梱する native 実行形式ではありません。Chrome 等の利用可否は実機の WebGPU 対応と管理ポリシーによります。

音声ボタンを押すと `AudioContext` を開始し、現在のシナリオを初めから再生します。有効化前の過去の起音を一斉に再発音しません。SFXだけの試聴ページは `audio/index.html` です。参考WAVは同じ合成コードから生成しましたが、長時間の保持・権威延長は実行時 voice で実現します。

## 5枝の現在設計

| 枝 | 原因と主形 | 保持・終端 |
|---|---|---|
| チャージ | 発動者の情報列が捕獲され、分離したバンクが噛み合う。準備完了時は中央の短い保持バスを追加。 | 1200msで準備形を保持。勝手に放出しない。権威解決・期限後は240ms以内に列を撤去。 |
| 通常放出 | 読出しゲートから有限長の搬送胴体が対象へ進み、先端packetが到達して対象側クランプと近傍応答を作る。 | 通常寿命520ms。設計到達180ms。解決された時点で経路の進行を止め、最大160msで撤去。未到達の命中表現を後から発生させない。 |
| 同位相共鳴 | 二入力が権威中点に入り、暗いハブ本体・三段共有スパイン・六放射の接続路へ再編成される。 | 1600ms。個別経路を退役させて空に戻す。通常2発の描画を重ねない。 |
| 逆位相相殺 | 左右の補対列が中央null trenchへ噛み合い、上から下へ進む消去前線に従って行単位で失われる。 | 1600ms。残存列と消去済み空間が同時にある。外向き放出やkill演出を勝手に作らない。 |
| ストレージロック | 対象の側部書込ゲートと背面棚がロック状態を示し、閉鎖時は短い前方バスが保持される。 | 必須の権威期限まで保持。延長は期限履歴だけ。終了後280msの列別解除はゲーム上の効果継続ではない。 |

## B Foundation / 選択拡張

`基底.md` は、**世界内の因果・観測系・truthful status** を分離するために継続適用しています。`拡張.md` からは以下だけを選択しています。

- **VFX**：5枝の世界内主形と時系列を記述するため。
- **PostEffects**：局所稜線から出る観測応答のみを扱い、主形の代用をさせないため。
- **LuminanceDynamicsModule**：白芯・暗部・退役の抑揚を管理するため。
- **VideoGenerationPolicy**：actor-time、ループプレビュー、検査窓を管理するため。

未選択理由は `design/extension-selection.json` に記載しています。人物造形系・グラデーション前提系の拡張は使っていません。

## 確認できる構成

自動ループ、全5枝の連続シナリオ、各枝単独、共鳴→相殺／相殺→共鳴、重なり、権威早期解決、ロック延長後の解除、`d=0`、連続イベントと重複通知を選べます。開始・中間・終端・消去へのシーク、`H64 = 64 CSS px` の原寸／2倍、明暗、`High 4xMSAA`／`Low 1x`、actor速度 `1x / 2x`、キャラcoverageの前後切替があります。

条件巡回は `13シナリオ × 明暗 × 品質 × 速度 × 倍率 × 3遮蔽 = 624条件` です。開始から消去まで時計を進め、相ごとの描画フレーム数、最大 actor 時間ステップ、発音台帳を記録します。**巡回完了や一枚のスクリーンショットは、全寿命の知覚品質・聴取の合格ではありません。**

H64原寸はブラウザ倍率100%で確認してください。画面が狭くても自動縮小しません。2倍表示で発動点から対象までを見る場合は十分な canvas 幅が必要です。H64の人型は host coverage の幾何的検査マスクであり、実ゲームの人物美術・姿勢・衣装との遮蔽確認を代替しません。

## 権威との境界

外部入口は `src/emp-e.js`、型は `src/emp-e.d.ts` です。`preview/` は独立しており、APIから import されません。`phase / pair / cause / owner` と元の権威期限は JSON snapshot で保存します。renderer はサーバー枝を選び直さず、見た目を HP、hitbox、ダメージ、storage 状態、cooldown へ書き込みません。

現在のサーバー原本は今回の添付にありません。確認対象はユーザー提供契約と r0.1 の API 資料で、実サーバー互換を確認済みとはしていません。Codex側はホストイベントからこの資産用 adapter へ意味を保って渡してください。旧Sol/Astraの造形・配色・層・音・コードは創作入力にしていません。

## 検査と状態

`npm test` は状態・幾何・PCM・AudioWorklet の JS 模擬試験です。`npm run validate` はローカルB構造検査、`npm run assets` はローカル参照、`npm run verify` は SHA-256 検証です。`npm run audio` は参考WAVを再生成します。ファイル更新後に manifest を再生成する場合は `npm run manifest`。実行ログもハッシュ対象なので、テストログを書き換えた後は元の manifest と一致しなくなります。

提出時の真の状態は `quality/report.json` と `quality/browser-run/report.json` を参照してください。この制作環境では Chromium の localhost 遷移が `ERR_BLOCKED_BY_ADMINISTRATOR` で拒否されました。**r0.3 の WGSL コンパイル、実WebGPU描画、実機H64、明暗・全寿命の品質、実聴は not_run** です。Node テスト成功を GPU・耳での検証に読み替えていません。

`P0` は `gallery/r0.1-p0/` にバイト不変で保存しました。完成版ではありません。ユーザーが確認できた範囲は P0 の共鳴 0.70 actor秒だけです。r0.1 の確認範囲も通常転送／共鳴の限定状態です。古い report は archive に隔離してあり、現行品質の合格証ではありません。
